# TaskFlow — Gestor de tareas

Aplicación web de gestión de tareas construida con React, TypeScript y Vite. Proyecto de portafolio para demostrar componentes, estado, formularios controlados, validaciones, filtros y persistencia local.

## Funcionalidades

- Crear, editar y eliminar tareas.
- Marcar tareas como completadas o pendientes.
- Buscar por título y notas.
- Filtrar todas las tareas, pendientes o completadas.
- Asignar prioridad y fecha límite.
- Guardado automático en `localStorage`.
- Validación de título y diseño responsive.

## Tecnologías

- React
- TypeScript
- Vite
- CSS
- Lucide React

## Requisitos

Node.js 20.19+ o 22.12+ recomendado y npm.

## Ejecutar en local

```bash
npm install
npm run dev
```

Abre en el navegador la dirección local que muestre Vite (normalmente `http://localhost:5173`).

## Comprobar compilación

```bash
npm run build
```

## Nota

Las tareas se guardan en el almacenamiento local del navegador. No hay backend ni cuenta de usuario en esta primera versión.
